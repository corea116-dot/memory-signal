# 메모리 신호

개인용 macOS 메뉴바 앱. 제공된 원본에서 분리한 풀·불꽃 아이콘으로 메모리 압력만 표시합니다.

## 동작

- 메뉴바 아이콘을 클릭하면 왼쪽 그래프와 오른쪽 메모리 통계 패널이 열립니다. 열린 상태에서도 2초마다 갱신합니다.
- 그래프는 최근 2분 동안 관측한 OS 정상·주의·위험 단계 이력입니다. 높이는 세 단계의 구분이며 사용률 퍼센트나 활성 상태 보기의 독자적인 연속 압력 지수가 아닙니다. 수집 전 구간 및 수집 공백은 채우지 않습니다.
- 물리 메모리, 사용된 메모리, 캐시된 파일, 사용된 스왑 공간을 표시합니다. 사용량은 `(internal - purgeable + wired + compressor) × page size`, 캐시는 `(external + purgeable) × page size` 추정값이며 물리 용량을 상한으로 둡니다. 스왑은 `vm.swapusage.xsu_used`를 읽습니다. 활동 모니터와 샘플 시점·산정 방식 차이로 값이 다를 수 있습니다.
- 표시는 1024 기반 GB/MB이며, 조회 실패한 항목은 `—`로 표시합니다. 패널 아래에 갱신 시각과 추정값 안내를 표시합니다.

- 초록 풀: 정상. 노란 작은 불꽃: 주의. 빨간 큰 불꽃: 위험.
- OS 메모리 압력 이벤트를 수신하고 2초마다 읽기 전용 상태 조회로 보완합니다. 잠자기에서 깨어나면 다시 읽습니다.
- 주의·위험으로 처음 진입하면 알립니다. 주의↔위험 전환 중에는 반복하지 않고 정상 관측 후에만 재알림합니다.
- 앱을 다시 실행해도 마지막 알림 여부를 유지합니다. 종료 중 정상 복귀를 관측하지 못한 경우, 다음 정상 상태를 직접 관측할 때까지 다시 알리지 않습니다.
- 알림 권한이 없으면 메뉴에서 설정 안내를 제공합니다. 전송 요청 실패는 60초 후 재시도합니다. OS의 집중 모드·알림 설정은 배너 표시를 제한할 수 있습니다.
- 최초 실행에서 로그인 자동 실행 등록을 요청합니다. 메뉴에 등록 상태를 표시하며, 승인 필요 시 시스템 설정으로 이동할 수 있습니다. 메뉴에서 자동 실행을 끌 수도 있습니다.
- 압력 조회 실패 또는 알 수 없는 값은 `?` 아이콘과 ‘확인 불가’ 설명을 표시합니다. 정상으로 오인하지 않도록 이전 압력 아이콘을 재사용하지 않습니다.
- RAM 정리, 스왑 조작, 프로세스 종료, 네트워크 통신 기능은 없습니다. 종료 메뉴는 이 앱만 종료합니다.

## 실행

빌드 후 이 저장소의 상위 폴더에 생성되는 `메모리 신호.app`이 실행 파일입니다. Apple Silicon, macOS 13 이상을 대상으로 빌드했으며 현재 Mac의 macOS 26.6.2에서 컴파일했습니다.

최초 실행 시 알림을 허용하고 메뉴에서 로그인 실행 상태를 확인합니다. 로그인 등록 후 앱 경로를 옮기면 다시 등록 상태를 확인해야 합니다. 이 빌드는 개인 로컬용 ad-hoc 서명이며 배포용 공증은 없습니다.

## 다시 빌드

이 폴더에서 `bash build.sh`를 실행합니다. Xcode Command Line Tools가 필요하며 외부 패키지 의존성은 없습니다. 빌드 스크립트는 아이콘 분리, 상태 로직 테스트, 앱 번들 생성과 서명 검증을 수행합니다. 앱을 자동으로 실행하지 않습니다.

`Package.swift`는 소스 편집·SwiftPM 컴파일용입니다. 실제 사용자 실행에는 리소스와 Info.plist가 포함된 `.app`을 사용합니다.

## 검증 상태

컴파일·상태 로직 테스트·아이콘 파일 읽기 검증을 통과했습니다. 사용자 스크린샷으로 그래프 패널 표시를 확인했습니다. 최신 빌드의 지속 갱신, 알림 배너, 재로그인 자동 실행 및 다른 Mac에서의 실행은 별도 검증이 필요합니다.
